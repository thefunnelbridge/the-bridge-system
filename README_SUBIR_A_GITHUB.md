# The Bridge System™ - Carpeta limpia para GitHub

Esta carpeta contiene solo los archivos necesarios para subir la app SaaS a GitHub y desplegar en Vercel.

Sube el contenido completo de esta carpeta al repositorio:

https://github.com/thefunnelbridge/the-bridge-system.git

## Incluye

- app
- components
- lib
- public
- package.json
- tsconfig.json
- next.config.ts
- tailwind.config.ts
- postcss.config.js
- next-env.d.ts
- .gitignore
- .vercelignore

## No incluye

- zips antiguos
- HTMLs antiguos
- carpetas duplicadas
- dist
- assets externos antiguos
- .DS_Store
- archivos de Systeme.io

## Comandos locales

```bash
npm install
npm run build
npm run dev
```

## Vercel

Framework: Next.js

Build command:

```bash
npm run build
```

Output: automático de Next.js.
